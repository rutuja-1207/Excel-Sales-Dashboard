# Documentation

## Project Overview

This project demonstrates the creation of an interactive Excel dashboard for sales analysis.

The dashboard helps analyze sales performance, profit, and overall business performance.

## Dashboard Pages

- Sales Dashboard
- Profit Dashboard
- Overview Dashboard

## Excel Features Used

- Pivot Tables
- Pivot Charts
- Slicers
- Conditional Formatting
- Formulas
- Interactive Dashboard

## Business Insights

The dashboard helps identify:

- Top-performing products
- Sales trends
- Profit trends
- Business performance
