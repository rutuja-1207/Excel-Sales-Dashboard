# 📊 Excel Sales Dashboard

## 📌 Project Overview

This project presents an interactive Sales Dashboard created using Microsoft Excel.

The dashboard helps analyze sales performance, profit, and overall business performance using interactive visualizations.

---

## 🎯 Business Objective

The objective of this project is to analyze business sales data and generate meaningful insights that support better business decisions.

---

## 🛠 Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Conditional Formatting
- Excel Formulas

---

## 📂 Workbook Structure

The workbook contains the following sheets:

- Data
- Analysis
- Dash
- Profit
- Overview
