# 📊 Excel Sales Dashboard

## 📌 Project Overview

This project presents an interactive Sales Dashboard created using Microsoft Excel.

The dashboard helps analyze sales performance, profit, and overall business performance using interactive visualizations.

---

## 🎯 Business Objective

The objective of this project is to analyze business sales data and generate meaningful insights that support better business decisions.

---

## 🛠 Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Conditional Formatting
- Excel Formulas

---

## 📂 Workbook Structure

The workbook contains the following sheets:

- Data
- Analysis
- Dash
- Profit
- Overview

---

## 📊 Dashboard Pages

### 📈 Sales Dashboard
Displays overall sales performance using interactive charts and KPIs.

### 💰 Profit Dashboard
Shows profit analysis, category-wise profit, and business performance.

### 📋 Overview Dashboard
Provides a summary of sales, profit, and other important business metrics.

---

## 📈 Analysis Performed

- Sales Analysis
- Profit Analysis
- Category-wise Analysis
- Region-wise Analysis
- Product Performance Analysis

---

## 💡 Key Insights

- Identified top-performing products.
- Compared sales and profit across categories.
- Analyzed business performance using interactive dashboards.
- Enabled easy filtering using slicers.
